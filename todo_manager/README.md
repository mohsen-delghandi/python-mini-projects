# Todo Manager

A simple command-line Todo Manager written in Python.

## Features

- Add a task
- Show all tasks
- Edit a task
- Complete a task
- Delete a task
- Save tasks to JSON
- Load tasks from JSON

## Requirements

- Python 3

## How to Run

```bash
python main.py
```

## Project Structure

```
todo_manager/
│── main.py
│── storage.py
│── tasks.json
│── README.md
```
